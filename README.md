# Dual-Gateway  软件功能说明

> 双协议栈高性能接入网关：高并发IoT网关，同支持C端千万级长连接和百万级IoT设备连接，单机支持百万级连接管理
> 一套进程同时承载 C 端移动 App WebSocket 长连接与百万级 IoT 设备的 MQTT-SN 接入，面向物联网 / 车联网 / 充电桩 / 智能硬件场景。

## 1. 设计目标



| 目标         | 说明                                      |
|------------|-----------------------------------------|
| 千万级 C 端长连接 | 移动 App 在线推送、远程控制，单机水平扩展至千万在线            |
| 百万级 IoT 设备 | 弱网、低功耗设备海量接入，支持 UDP / DTLS / QUIC 三路传输  |
| 单机高性能      | 接入解耦、无锁计数、异步外部依赖、连接池化，单机数万至十万在线         |
| 高可用        | Redis/Kafka 不可用时自动降级，不阻塞主路径；优雅关闭、影子离线兜底 |
| 单机性能       | C端百万级TCP长连接，IoT端百万量级设备MQTT接入            |

## 3. 功能特性

### 3.1 C 端接入（WebSocket + Protobuf）

* 协议：`ws://host:8080/ws`，自定义二进制帧 `[2B headerLen][protobuf Header][protobuf Body]`，魔数 `0xABCD`。

* 消息类型：`AUTH / AUTH_ACK / HEARTBEAT / HEARTBEAT_ACK / MESSAGE / MESSAGE_ACK / PUSH / ERROR`。

* 鉴权：JWT RS256，签发含 `user_id/device_id`，支持过期与 issuer 校验；密钥缺失时自动生成（开发态）。

* 长连接保活：服务端 30s Ping、90s Pong 刷新、120s 无活动判离线。

* 业务消息：转发 Kafka、影子查询、充电指令（`charge.start/stop`、`set.param`、`query`）、影子订阅 / 退订。

### 3.2 IoT 接入（MQTT-SN 三路协议传输）

* **UDP 明文（5683）**：无连接数据报，适合海量弱网设备；独立源 IP 限流防伪造洪峰。

* **DTLS-PSK（5684）**：按设备 PSK 查表，未登记设备走默认 PSK；支持 AES-128-CCM/GCM 套件。

* **QUIC（5685）**：TLS1.3 + 0-RTT 重连 + 连接迁移，单流串行承接，降低并发 goroutine 数。

* MQTT-SN 扩展报文：`STATUS(0x1E)` 桩状态上报、`FETCH(0x1F)` 唤醒拉指令、`CMD(0x20)` 下行、`CMDACK(0x21)` 执行回执、`RETRYINFO(0x22)` 限流重试。

* 会话管理：同设备重连替换旧会话，300s 无活动清理并影子置离线。

### 3.3 设备影子（Device Shadow）



* 桩权威状态（idle/charging/fault/preoccupy/offline），版本号递增。

* **原子抢桩**：`charge.start` 先 `TryPreoccupy`（防双人抢桩，409 拒绝）。

* 预占超时自动回滚（60s 未确认恢复空闲）、离线 TTL（120s）判定、离线扫描回滚。

* 状态变更经 Pub/Sub 推送给订阅该桩的 C 端；C 端一律走影子查询，绝不直连弱网桩。

### 3.4 指令队列



* 指令唯一 ID 幂等入队，待执行指令 TTL 24h、批量下发（≤10）。

* 在线设备：C 端入队后经 Pub/Sub 立即触发本节点直发；离线设备：指令留队，设备唤醒（FETCH/PINGREQ 捎带）即拉取。

* CMDACK 回执闭环：更新队列完成态、同步影子、发布结果事件给 C 端。

### 3.5 横向能力



* **Redis**：在线用户 / 设备注册、网关注册发现、跨节点消息转发、影子与指令队列存储；连不上时自动降级本地内存。

* **Kafka**：C 端消息、IoT 遥测事件转发业务系统；连不上时丢弃计数，不阻塞协议。

* **分层限流**：CONNECT 令牌桶、UDP 源 IP 桶、C 端 accept 节流；超限快速拒绝 + RetryInfo。

* **可观测**：`/metrics`（Prometheus）、`/health`（全量运行态 JSON）、`/admin` 可视化后台（实时指标、影子查询、压测编排、一键全功能验收）。

* **优雅关闭**：SIGINT/SIGTERM，30s 超时，停机时本节点全部设备影子置离线。

## 4. 技术亮点


1. **主路径零阻塞**：IoT CONNECT 只做内存查表回包，外部依赖（Redis/Kafka）全部异步化，5 万并发握手连接池健壮0错误，连接池不打满。

2. **收发解耦**：读循环只入队（1M 容量吸收洪峰），worker 池并行处理；队列满按计数丢弃而非阻塞读循环。

3. **内存极致**：C 端缓冲 4KB、数据报 / 消息 `sync.Pool`、`atomic` 无锁计数，单 C 端连接约 20KB。DTLS 读缓冲按 MTU(1200) 收敛到 1.5KB/连接，单连接常驻约 65KB，实测 5000 DTLS 零错误零丢包，证实十万/百万级在线能力。

4. **三传输统一抽象**：`Peer` 统一 UDP/DTLS/QUIC 端点，业务处理与传输解耦，下行直发自动选择流 / 连接 / 数据报。

5. **降级优先**：Redis/Kafka/JWT/QUIC 证书缺失均有兜底，单机可零依赖启动（自动生成密钥 / 自签证书）。

6. **内置压测与验收**：admin 后台可一键跑 C 端 / IoT 压测与 “健康→鉴权→指令闭环→影子” 全链路验收。
